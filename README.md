# Yunekoto — GitHub Pages

Static portfolio for `yunekoto-dev.github.io`.

## Deploy
Put the contents of this folder in a GitHub Pages repository named `yunekoto-dev.github.io`.

The page is dependency-free at runtime. The GitHub section reads public repository data from the GitHub REST API in the browser.

## Terminal
Try `help`, `about`, `projects`, `stack`, `github`, `contact`, `cat`, or `neofetch`.
